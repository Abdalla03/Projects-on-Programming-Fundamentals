# Projects on Programming Fundamentals

A collection of small projects built while learning the fundamentals of programming.

## Projects

| # | Project | Description |
|---|---------|-------------|
| 1 | [Student Grade Calculator](./Student-Grade-Calculator) | Calculates student grades (C++, Visual Studio project). |
| 2 | [Number Guessing Game](./Number-Guessing-Game) | Guess the secret number game (C++, Visual Studio project). |
| 3 | [To-Do List Manager](./To-Do-List-Manager) | Manage a simple list of tasks saved to a file (C++, Visual Studio project). |
| 4 | [Rock Paper Scissors Game](./Rock-Paper-Scissors-Game) | Classic Rock-Paper-Scissors against the computer (C++, Visual Studio project). |

Each project also has its own repository on GitHub: `Student-Grade-Calculator`, `Number-Guessing-Game`, `To-Do-List-Manager`, `Rock-Paper-Scissors-Game`.
